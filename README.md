# Gardner Cleaning & Care Co. — Website

A simple one-page site for the business, ready to publish with GitHub Pages.

## What's here
- `index.html` — the whole site
- `style.css` — styling (colors, fonts, layout)
- `assets/logo.png` — logo, transparent background
- `assets/favicon.png` — small icon mark, used as the browser tab icon
- `assets/ben-photo.jpg` — hero photo

## Publish it with GitHub Pages
1. Create a new repository on GitHub (e.g. `gardner-cleaning-care`).
2. Upload all the files in this folder, keeping the `assets` folder structure intact.
3. In the repo, go to **Settings → Pages**.
4. Under "Build and deployment", set **Source** to "Deploy from a branch", branch `main`, folder `/ (root)`.
5. Save. GitHub will give you a URL like `https://yourusername.github.io/gardner-cleaning-care/` within a minute or two.

## Things to fill in before publishing
- The "About Ben" section on the page has a highlighted placeholder — replace it with a real line about his education or background.
- If you get a custom domain later, add a `CNAME` file with the domain name at the root, and set it under Settings → Pages.

## Editing later
Everything is plain HTML/CSS — open `index.html` and `style.css` in any text editor. No build step, no dependencies.
